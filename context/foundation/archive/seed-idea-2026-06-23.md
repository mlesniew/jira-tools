# Jira & Confluence 

I'd like to set up a set of skills for Claude which will
be able to read data from Jira and Confluence and help the
user learn the full context of their Jira tickets to prepare
for meetings and plannings.


## Features 

* Load Jira ticket titles, descriptions, comments and links into markdown files or Claude
* Load Confluence page content into markdown files or Claude
* Add capability to automatically load data from related (linked) Jira tickets or Confluence pages.
* Support user in collecting the full context for a ticket
* Supporting the user in running research on technical topics, possible implementation approaches
* Supporting user in planning preperation -- finding requirement gaps, highlighting risks, etc.


## Out of scope for initial version

Adding new data into Jira or Confluence.


## Technical details

* The data can be retrieved from Jira using the official acli tool
* There's also a Python library (Atlassian Python API): https://atlassian-python-api.readthedocs.io/
* One problem is that Atlassian systems store data in a special json-based format.  We need to be able to convert it to Markdown for readability and easier parsing.  It will be easier to work with this way for both humans and agents.
* Only basic formatting support is needed for a start.
* If any tools need to be written to support this, let's try to use Python based ones first.  Second choice would be JS or TS.  Focus on Ubuntu support first of all.  This will match the team's typical setup.
